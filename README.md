# EWB Phishing URL Awareness Checker

## About the Project
This is a Python-based cybersecurity mini project that checks URLs for common phishing warning signs.

## Features
- Detects suspicious URL patterns.
- Checks HTTP and HTTPS connections.
- Identifies IP addresses in URLs.
- Detects suspicious keywords.
- Displays warning messages.

## Technologies Used
- Python 3
- Visual Studio Code

## How to Run
1. Install Python.
2. Open the project in VS Code.
3. Open the terminal.
4. Run: python phishing_checker.py
5. Enter a sample URL.
6. View the results.

## Disclaimer
This project performs basic text-based URL checks. It does not open URLs or guarantee website safety.
